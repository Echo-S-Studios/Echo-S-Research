# Code — `2026-07-relational-charge`

Producer scripts for **"Relational Charge on the Spectral Semiring: Gauge
Rigidity, Coherence Types, and a Reference-Free Parity Floor"**
(`papers/2026-07-relational-charge/relational_charge_paper.tex`).

Each script computes a result and **writes** machine-readable output to
`data/2026-07-relational-charge/`. Every data file self-identifies its
provenance (CSV: leading `# source: … ; generated by: …` comment; JSON:
`_source_paper` / `_generated_by` fields).

Run from the repository root with the `py` launcher, e.g.
`py code/2026-07-relational-charge/contact_signatures.py`.

## How these differ from `tests/`

`tests/` are **independent verifiers**; `code/` are **producers**. The producer
decision procedure here (`relcharge_core.cyclotomic_contacts`) is the paper's
**own** probe from Appendix B: it trial-divides each ratio polynomial by every
cyclotomic `Phi_M` up to the complete totient bound `M ≤ 2 (deg P)²` of
Lemma 4.5, in exact integer/rational arithmetic. The test suite deliberately
uses a *different* algorithm (factor the ratio polynomial over `Q` and name the
cyclotomic factors) as a cross-check. The producers `main()` **emit data**;
they contain no asserts and do not import from `tests/`.

### Notes on the corrected census split

Per the recent erratum, the degree-12 census rejection tally uses the **256/46**
split (256 trace-Sturm rejects / 46 reducible), not the old 257/45: the single
class `x¹²−x¹¹−x¹⁰−x⁹−x⁷−x⁶−x⁵−x³−x²−x+1` carries a `Φ₁₀` factor and is bucketed
reducible despite a coincidental `(1,0,5)` trace pattern. Robust invariants are
unchanged: 39 vanish, 37 Salem, 378 orbits, combined trace+reducible = 302.
