# Code — `2026-06-lambda-2c`

Producer scripts for the paper **"The Exchange Rate λ = 2c: A Conformal Identity,
Its Gate, and Its Flip"** (`papers/2026-06-lambda-2c/lambda_2c_paper.tex`).

Each script computes a paper result in exact (sympy) or high-precision (mpmath)
arithmetic and **emits** machine-readable output to `data/2026-06-lambda-2c/`.
These are *producers*: they write data, they do not assert. The independent
verifiers live in `tests/2026-06-lambda-2c/` and are kept separate (this code does
not import them, and vice versa). Where the tests assert `computed == paper_value`,
the producers instead serialize the computed objects (tables, matrices, charpolys,
measures, constants) so the paper's concrete results are reproducible as data.

## Requirements

Python via the `py` launcher, with `sympy`, `mpmath`, `numpy` (no other deps).
`lambda2c_common.py` is a shared helper module (Mahler measures, companion
matrices, the Lie self-action `ad_R`, Fibonacci, provenance-stamped CSV/JSON
writers); it is imported by the producers and is not run on its own.

comment; JSONs carry `_source_paper` and `_generated_by` fields.
