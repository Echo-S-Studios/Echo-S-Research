# Code — The Emission Algebra 𝔄 (2026-07 primer)

Producer scripts for **papers/2026-07-emission-algebra-primer/emission_algebra_primer.tex**
("The Emission Algebra 𝔄 — one matrix, one relation, three layers", AceTheDactyl /
Echo S Studios Research Developments).

Each producer computes a paper result **in exact arithmetic** and writes a
machine-readable artifact to `data/2026-07-emission-algebra-primer/`. Every CSV
carries a leading `# source: … ; generated by: …` provenance comment; every JSON
carries `_source_paper` and `_generated_by` fields.

These are **producers**, complementary to the independent verifiers in
`tests/2026-07-emission-algebra-primer/`. The tests *assert* each paper value;
these scripts *emit* the same results as data (functions + a `main()` that writes
files, no asserts). They do **not** import from `tests/`.

Run from the repo root with the `py` launcher, e.g.

```
py code/2026-07-emission-algebra-primer/d1_keystone_powerlaw.py
```
