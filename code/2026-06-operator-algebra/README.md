# Code — `2026-06-operator-algebra`

Producer scripts for **"The Operator Algebra of the Emission Semiring — A
λ-Ring, the Adams Square, and Two Characters"**
(`papers/2026-06-operator-algebra/operator-algebra-whitepaper.tex`).

Each script re-implements the paper's Definitions (Sec. 2–5) from scratch and,
run as `py code/2026-06-operator-algebra/<name>.py`, **computes and emits**
machine-readable results to `data/2026-06-operator-algebra/`. These are
*producers*: they instantiate the paper's laws on the concrete seed catalogue
and write the computed values (measures, charges, multisets, sequences). This
is the complement of `tests/2026-06-operator-algebra/`, whose scripts *assert*
the same laws over generic symbols — the code here **emits data, never asserts**.

All algebra is exact (`sympy`) or high-precision (`mpmath`, ≥ 45–60 dp). The
shared toolkit `opalg_core.py` is imported by every producer; nothing imports
from `tests/`.

## Reproduce everything

```
py code/2026-06-operator-algebra/opalg_core.py
py code/2026-06-operator-algebra/semiring_laws.py
py code/2026-06-operator-algebra/adams_plethysm.py
py code/2026-06-operator-algebra/mahler_character.py
py code/2026-06-operator-algebra/floor_monoid.py
py code/2026-06-operator-algebra/charge_character.py
py code/2026-06-operator-algebra/self_action_rates.py
py code/2026-06-operator-algebra/fixed_points.py
py code/2026-06-operator-algebra/unified.py
```

Each CSV begins with a `# source: … ; generated by: …` provenance comment;
each JSON carries `_source_paper` and `_generated_by` fields.
