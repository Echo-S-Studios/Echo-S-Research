# Code — 2026-06-emission-gap

Producer scripts for **_The Emission–Gap Theorem: No Salem Number in the Spectral
Image, and the Cost Floor It Forces_** (AceTheDactyl / Echo S Studios).
Source paper: [`papers/2026-06-emission-gap/emission_gap_paper.tex`](../../papers/2026-06-emission-gap/emission_gap_paper.tex).

Each script has a `main()` that **computes a result and emits machine-readable
output** to [`data/2026-06-emission-gap/`](../../data/2026-06-emission-gap/) — it
does not assert. (This is the deliberate difference from the independent verifier
suite in `tests/2026-06-emission-gap/`, which re-derives the same quantities and
`assert`s them against the paper's printed values. The producers here share no
code with the tests: all primitives live in the self-contained `emgap_core.py`.)

Run from the repository root with the `py` launcher. Dependencies: `sympy`,
`mpmath`, `numpy` (already installed). Every data file self-identifies its
provenance (CSV: a leading `# source: …; generated by: …` comment; JSON:
`_source_paper` / `_generated_by` fields).

## Shared library

| File | Role |
|------|------|
| `emgap_core.py` | Clean, independent re-implementation of the paper's primitives: high-precision roots & Mahler measure (mpmath ≥ 50 dps), the trace-down `R(x)=x^m T(x+1/x)` via the Chebyshev recurrence, the exact Salem flip-straddle guard (palindromy + Sturm root counting), field / trace-form signatures (the trace form's inertia is counted **exactly** via Sturm on the integer Gram matrix's characteristic polynomial), companion matrices, and the self-action `ad_M`. Also the catalog (`CATALOG`) and Lehmer (`LEHMER`) constants and the CSV/JSON emit helpers. Imported by every producer; not run directly. |

## Note on sample-dependent tallies

Two of the paper's Appendix-A numbers are enumeration/RNG-dependent tallies that
the paper does not fully pin (as the test suite's `NOTES.md` records). These
producers reproduce them **deterministically** and report the structural
invariant, which is what the propositions actually assert:

- **Circulant scan (Prop. 12.3).** With the fixed seed `20260604` and the tests'
  parameters (n∈{4,5,6}, entries in [−3,3], 400 trials) the scan yields **1137**
  irreducible factors here vs. the paper's "1126" — a run/version-dependent count.
  Both give the load-bearing result: **0 Salem factors.**
- **Commutator slice (Prop. 8.6).** Over the tests' generating slice (catalog
  companions + kron/dsum of the first three size-2 companions) the scan finds
  **2 distinct** reciprocal factors of degree ≥ 4 (32 occurrences over 397
  commutators) vs. the paper's "4" for its (unpinned) slice. Again the invariant
  holds: **0 Salem-eligible factors.**

All non-tally results reproduce the paper's printed values exactly in exact /
high-precision arithmetic.
