# Code — Residual Return: Exact Learning Dynamics and Language over the Vector Substrate

Producer scripts for `papers/2026-06-residual-return-learning/residual_return_learning.tex`.

Each script has a `main()` that **computes** the paper's concrete results and **emits**
machine-readable data to `data/2026-06-residual-return-learning/` (JSON with
`_source_paper` / `_generated_by` fields; CSV with a `# source: … generated by: …`
header line). These are *producers*, independent of the *verifiers* in
`tests/2026-06-residual-return-learning/`: the tests `assert` values with sympy's
black-box helpers, while the code re-implements the paper's own procedures (e.g. the
seed-naming bridge as the **largest invariant factor** of the characteristic matrix via
determinantal divisors over `Q[x]`, exactly as Theorem 3.3 prescribes) and writes their
output. No script imports from `tests/`.

Environment: use the `py` launcher (Windows). Requires `sympy`, `mpmath`, and — for
`make_figures.py` only — `PyMuPDF` (`fitz`) and MiKTeX XeLaTeX. All decisions are exact
(`Fraction`/`Integer`); only Mahler measure and transcendental log-enclosures use mpmath,
never inside a decision.

`rrl_core.py` is a shared, non-executable module of reusable primitives (companion matrix,
trace-form Gram, exact projector, the invariant-factor bridge, the Clifford `Cl(2,0)≅M₂(R)`
isomorphism, Mahler measure, the SHA-256 witness link, and the provenance writers).
