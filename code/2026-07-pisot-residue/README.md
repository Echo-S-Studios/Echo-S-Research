# Code — *The Pisot Cross-Shell Residue*

Producer scripts for **`papers/2026-07-pisot-residue/pisot_residue_whitepaper.tex`**
(AceTheDactyl, Echo S Studios Research Developments, July 2026).

Each script rebuilds the paper's objects **from scratch** — companion matrices,
resultants, high-precision roots, exact cyclotomic factor-matching — and **emits
machine-readable output** to `data/2026-07-pisot-residue/`. These are *producers*
(functions + a `main()` that writes data); they are independent of, and do not
import from, the verifier suite in `tests/2026-07-pisot-residue/`.

Run everything with the Windows `py` launcher (Python 3.12; sympy 1.14, mpmath 1.3,
numpy 2.4, pymupdf 1.28). Scripts import the shared engine `pisot_lib.py`, which sits
in this folder, so run them as-is (Python puts the script's own directory on the path):

## Provenance

- **JSON** artifacts carry `_source_paper` and `_generated_by` fields.
- **CSV** artifacts carry a leading `# source: …; generated by: …` comment line.

## Notes on values

Consistent with the current `.tex`/tests (2026-07-04 errata): the degree-12 Salem
census intermediate split is **256** trace-Sturm rejects / **46** reducible (the
Φ₁₀-factored class with a coincidental (1,0,5) trace pattern is reducible, not a
trace-Sturm reject), with 39 (±1 root) / 37 Salem / 378 orbits / **302** combined.
All decision-critical quantities are exact (resultants, factorization, Sturm
counts); numeric root moduli/θ values are labelled *display* and carry no decision
weight — sound here because the certified sets are irreducible and non-reciprocal
(no root on the unit circle).

## How these differ from `tests/`

`tests/` are independent **verifiers** (pytest `assert`s that re-derive each paper
number and check it). `code/` here are **producers**: the same mathematics is
re-implemented cleanly as reusable functions whose `main()` *emits* the results as
CSV/JSON data rather than asserting them. No file here imports from `tests/`.
