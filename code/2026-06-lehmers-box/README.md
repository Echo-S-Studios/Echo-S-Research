# Code — *Lehmer's Box*

Producer scripts for **`papers/2026-06-lehmers-box/lehmers_box.tex`**
("Lehmer's Box: A Golden Floor and an Angle Lattice that Confine Spectral
Emission Away from Salem Numbers — Without Resolving Lehmer's Problem",
AceTheDactyl / Echo S Studios Research Developments).

Each script **computes a result and writes machine-readable output** to
`data/2026-06-lehmers-box/` (or, for the figure builder, to
`figures/2026-06-lehmers-box/`). Every artifact self-identifies its provenance
(CSV leading `# source: …; generated by: …` comment; JSON `_source_paper` /
`_generated_by` fields).

These are **producers** (functions + a `main()` that *emits* data). They are
independent of `tests/2026-06-lehmers-box/` (the tests are *verifiers* that
assert against the paper; nothing here imports them, and no paper number is
copied — every value is re-derived from its defining polynomial / closed form /
Galois construction).

## Environment

Use the `py` launcher (Python 3.12; sympy 1.14, mpmath 1.3, numpy 2.4,
matplotlib 3.11, pymupdf/`fitz` 1.28). Figures compile with the MiKTeX XeLaTeX.
Run every command from the repository root `Echo-S-Research/`.

## Shared modules (not run directly)

| Module | Role |
|---|---|
| `box_core.py` | computational core — Mahler measure (product & Jensen forms), root/Salem classification, exact `Q(sqrt5)` sign, the seed catalog, trace-down, closure-guard ladder, self-action spectrum, and the Galois census of `K`. |
| `box_io.py` | provenance-stamped CSV/JSON writers. |

| `floor_wall.py` | `py code/2026-06-lehmers-box/floor_wall.py` | `floor_strip_scan.csv` (all 625 quadratics), `floor_wall_summary.json` → Lem. 3.1 empty strip `(1,phi)` + minimiser `phi` at disc 5; Lem. 3.2 / Rem. 3.3 operator floor. |
| `lattice_walls.py` | `py code/2026-06-lehmers-box/lattice_walls.py` | `catalog_arguments.csv`, `box_membership.csv`, `lattice_walls.json` → Lem. 4.1–4.4 (`(pi/2)Z` walls, `mu_4`, `K` split, Salem off-lattice); Thm. 4.6/4.7 box membership (catalog in; Lehmer & `beta_4` out). |
