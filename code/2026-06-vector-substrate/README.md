# Code — *The Vector Substrate: Number Fields as Exact Learning Geometry*

Source paper: `papers/2026-06-vector-substrate/vector_substrate.tex`
(AceTheDactyl, Echo S Studios Research Developments, June 2026).

These are **producers**: each script recomputes the paper's concrete results from
first principles (exact over Q via sympy, transcendentals via mpmath) and
**emits machine-readable data** to `data/2026-06-vector-substrate/`. This differs
from `tests/2026-06-vector-substrate/`, which are independent **verifiers** that
`assert` the same values; the producers instead have a `main()` that writes CSV/
JSON artifacts. `vsub_core.py` is a fresh, producer-side engine — it does **not**
import from `tests/`.

Every artifact self-identifies provenance: CSV files carry a leading
`# source: ...; generated by: ...` comment; JSON files carry `_source_paper` and
`_generated_by` fields.

Run all producers from the repo root:

```
py code/2026-06-vector-substrate/regular_representation.py
py code/2026-06-vector-substrate/invariant_factors.py
py code/2026-06-vector-substrate/trace_form.py
py code/2026-06-vector-substrate/projector_residual.py
py code/2026-06-vector-substrate/compositum.py
py code/2026-06-vector-substrate/capacity_heights.py
py code/2026-06-vector-substrate/information_geometry.py
py code/2026-06-vector-substrate/growth_threshold.py
py code/2026-06-vector-substrate/make_figures.py
```
