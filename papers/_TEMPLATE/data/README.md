# data/__FOLDER__/

Machine-readable outputs (CSV/JSON) for **papers/__FOLDER__/**, generated by the
producers in `code/__FOLDER__/`. Regenerate with `py code/__FOLDER__/producer.py`
(and any other producer scripts you add).

Every file must self-identify its provenance:

- **CSV** → a leading `# source: papers/__FOLDER__/…; generated by: code/__FOLDER__/…` comment line.
- **JSON** → top-level `_source_paper` and `_generated_by` fields.

The `drift` CI regenerates these and fails if they differ from what's committed —
so keep your producers deterministic (seed any RNG).
