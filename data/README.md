# Data

Datasets and machine-readable outputs (CSV/JSON) that support the papers in [`papers/`](../papers).

Every file self-identifies its provenance: CSVs carry a leading `# source: papers/…; generated by: code/…` comment, JSON files carry `_source_paper` and `_generated_by` fields. All values use the corrected errata (degree-12 census 256/46, z5 reciprocal 4, salem-slot `−φ⁻³`, lehmers-box 27 subfields, `R₁∼−R`).
